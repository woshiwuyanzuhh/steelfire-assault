# 全产品验收矩阵

| 工单 | 必须看到的证据 | 失败条件 |
| --- | --- | --- |
| 01 产品基线 | 规格、术语、标准和工单阻塞关系 | 目标或口径仍依赖旧原型 |
| 02 Blender 视觉开发 | 次世代细节静帧、近景、工程文件 | 明显 primitive 占位、无法编辑或无细节 |
| 03 90 秒镜头 | 2160 帧、分镜清单、关键帧 contact sheet | 时长不足、镜头断裂或无法重渲染 |
| 04 自然配音 | 90 秒母带、cue 表、手机/耳机试听 | 电子感明显、台词被底床覆盖、漂移 |
| 05 人物交互 | 真机录像/日志、输入和状态验证 | 多指丢输入、死亡卡死、动画与判定不同步 |
| 06 战斗 | 武器/敌人/载具/Boss 完整战斗记录 | 攻击无预警、阶段无差异、载具状态卡死 |
| 07 关卡 | 从教学到结算的完整录像、检查点重试 | 波次重复、节奏无决策点、重试污染状态 |
| 08 UI/存档 | 菜单/HUD/设置/损坏存档/后台记录 | 文案不可读、存档阻断启动、覆盖安全区 |
| 09 性能/设备 | iQOO 13、低性能、断网、冷启动数据 | 未实测、崩溃、严重掉帧或网络依赖 |
| 10 交付 | APK、SHA、Blender、MP4、来源和报告 | 任一工单未闭单或交付物不一致 |
