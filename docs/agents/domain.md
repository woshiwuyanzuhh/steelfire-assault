# Domain docs

This is a single-context repository. Read `PRD.md`, `TECH_DESIGN.md`,
`GAME_DESIGN.md`, `AGENTS.md`, and `ASSET_SOURCES.md` before changing the
product. Architecture decisions belong in `docs/adr/` when a ticket creates a
long-lived constraint; the 90-second Blender CG tickets use the existing
product documents unless a new decision needs recording.
