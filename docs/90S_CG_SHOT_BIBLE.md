# 90 秒 Blender CG 镜头圣经

这份文档是《钢火突袭》90 秒片头的创作与验收基准。它与 `.scratch/90s-blender-cg/issues/02`、`03`、`04` 配套使用；镜头、旁白、字幕和工程文件必须以同一份时间线为准。

## 视觉目标

- 题材：锈潮港地下维修坞在反应堆失控前的撤离行动。
- 视觉：写实军事工业插画的形体语言，硬表面结构、湿地面反射、冷青工作光与橙色警示光形成冷暖对照。
- 资产：原创六轮回收车、闸门机、维护无人机、灰脊操作员、反应堆与维修坞。所有资产保持 Blender 可编辑，运行时不读取网络资源。
- 镜头：24 fps、90.0 秒、2160 帧；近景必须能读出装甲分层、接缝、紧固件、液压线、玻璃、磨损与发光件，中远景必须保留明确剪影和动作方向。

## 声音与画面验收

- 旁白母带：`app/src/main/assets/audio/cg/intro_voiceover_90s.wav`，90.0 秒、22.05 kHz、16-bit、单声道。
- cue 点：8/18/28/38/49/59/69/78/86 秒；视频编码后每个 cue 与画面切点偏差小于 80 ms。
- 最终 MP4：H.264 视频 + AAC 音频，24 fps，90.0 秒；编码只能使用本地帧序列和本地音频。
- 语音清晰度：旁白峰值不得削波；无线电层可以有带宽限制，但不能压过叙事层；环境底床不能在标题停留段制造突发峰值。

## 返工门槛

出现以下任意情况，镜头不得进入全量渲染：

1. 近景可见只有无材质方块或重复贴图的占位几何。
2. 轮组、炮塔、操作员或无人机在接触表中没有可读动作。
3. 黑位吞没主体，或者发光件过曝导致无法辨认结构。
4. 镜头切点、旁白 cue、标题安全区或结尾时长不满足工单 03/04。
5. 工程文件无法在 Blender 5.2.2 中重新打开、调整镜头并保存。
