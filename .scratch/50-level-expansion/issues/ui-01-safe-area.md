# UI-01：横屏安全区与 UI 错位修正

**目标**：修复不同横屏比例、系统导航栏、刘海/挖孔和 letterbox 下标题、HUD、暂停层与触控按钮的错位、裁切和点击区域偏移。

**Blocked by**：00：50 关扩展基线与章节验收协议

**Status**：in_progress（代码实现与静态检查已通过；设备截图验收待重新连接测试机）

## 问题定义

- 当前逻辑画布是 1280×720，但设备窗口可能是 2376×1080、超宽屏或存在安全区 inset；绘制和触摸逆映射必须使用同一安全矩形。
- HUD、暂停按钮、右下角操作区和模态按钮不能落入黑边、系统手势区或可见内容之外。
- 文案不能因为缩放、字体度量或长关卡名被裁切；可用关卡和锁定关卡必须有明度与文字双重差异。

## 实现范围

- 在 `MainActivity` 读取 `WindowInsets`，将安全区传给 `GameView`，形成可复用的 `ViewportTransform`/等价数据对象。
- 绘制、点击、拖动、多指 pointerId 和截图证据统一使用同一矩阵；禁止在单个按钮中重新计算偏移。
- 为菜单、HUD、暂停、检查点、结算和关卡选择定义安全矩形和最小点击区域（≥72dp）。
- 在 16:9、20:9、设备旋转/恢复和系统栏显示变化下验证无跳位。

## 验收标准

- [ ] 1280×720、1920×1080、2376×1080 和至少一个带 inset 的横屏窗口截图中，文案、HUD、按钮完整可见。
- [ ] 触摸按钮的可见边界与命中边界误差 ≤ 4 个逻辑像素；黑边点击不会误触战斗操作。
- [ ] 切后台/返回、暂停/继续和重新进入关卡不改变安全矩形或按钮位置。
- [ ] 低性能模式只减少表现层，不改变安全矩形、文字层级、敌人预警或命中判定。
