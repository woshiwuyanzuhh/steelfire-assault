# 50 关素材策略（Asset Strategy）

**适用范围：** `.scratch/50-level-expansion/issues/level-01..50-*.md` 与后续实现工单。
**目标：** 在不依赖运行时网络、不使用商业游戏表达的前提下，为 50 个可独立验收的关卡提供可追溯、可复现、可降级的图片、动画、音频、字体和关卡装饰。

## 1. 约束与验收原则

1. APK 运行时只从 `app/src/main/assets/`、`res/drawable*` 和本地代码读取素材；禁止 CDN、远程字体、热链图片、网络音频和运行时下载。
2. 不导入或改绘《合金弹头》及其他商业游戏的角色、地图、台词、字体、音乐、音效、商标、UI 结构或可识别构图。每个章节使用原创名称、原创轮廓和原创配色。
3. 外部素材只接受 `ASSET_SOURCES.md` 已记录的 CC0/公有领域包；导入前保存原始许可证、下载日期、URL、压缩包 SHA-256 和本地目录。无法确认许可的资源只作为参考，不进入 APK。
4. 优先程序化绘制和项目原创生成：场景砖块、粒子、扫描线、环境雾、弹道、按钮图标、HUD 图表和 Boss 弱点状态都应由 Kotlin Canvas 或离线脚本生成，减少 APK 体积并保证风格一致。
5. 生成素材须保存生成脚本、参数 JSON、输入引用和输出 SHA-256。素材改变时更新来源表和对应工单资源清单，避免“生成过但无法重建”。
6. 每项图片提供 1x/2x 密度或矢量/参数化替代；音效统一采样率、峰值和长度；任何动态效果必须在低性能模式提供静态轮廓或低粒子降级。

## 2. 来源优先级

### A. 项目内程序化（首选）

- **场景与机关：** 使用 `tools/` 下的离线 Python/Blender/PNG 脚本生成瓦片、管线、列车、温室、井壁、镜面和反应堆部件。参数包括基色、边缘高光、锈蚀密度、灯带频率、碰撞矩形；脚本输出 PNG/SVG 及 JSON 元数据。
- **粒子与特效：** Canvas 绘制圆弧、线段、噪声采样、半透明叠层和固定种子粒子；不把每帧中间图导入 APK。固定步长下复现同一轨迹，低性能模式将粒子数量降至默认的 35% 并保留预警形状。
- **UI 与图标：** 所有按钮、状态环、阶段条、触控提示使用 `VisualTokens.kt` 的颜色和几何 token；只用 Android 系统无版权依赖的字体栈和本地简体中文字形，禁止远程字体。
- **音频：** 使用本地 PCM/NumPy 生成枪声、冲击、蒸汽、警报、机关和 Boss 阶段提示，导出 OGG/WAV；音频生成脚本和 cue 表放在 `tools/audio/`，运行时只播放已打包文件。

### B. 项目原创离线生成

- 新角色、敌人、Boss 和章节关键图可由本项目绘图/Blender/本地 ImageGen 生成，但必须经过原创边界检查：无商业角色姿态复制、无商标、无现成游戏 HUD、无未经许可字体或纹理。
- 生成提示词、参考图路径、编辑步骤、裁切尺寸、透明背景设置和最终 SHA-256 写入 `.scratch/50-level-expansion/audits/assets/`。参考图不得进入 APK，除非其许可已登记。
- 角色精灵采用统一骨骼比例和 8/12/16 帧状态表；每个敌人至少有待机、预警、攻击、受击、死亡五种读法，Boss 额外提供三阶段弱点姿态。

### C. 已登记 CC0 资源（补充）

可以复用 `ASSET_SOURCES.md` 已记录的 Kenney、OpenGameArt CC0 包，但接入时只截取必要元素并通过统一调色、轮廓和比例进行原创化组合，不照搬原包示例关卡。每次实际接入必须在来源表追加：包版本/下载日期、URL、压缩包 SHA-256、许可证文件路径、裁切/改色脚本和 APK 内路径。

当前可优先评估的本地候选包括：工业图块、科幻平台图块、实验室图块、机器人参考、Kenney 工业/科幻/Impact/Digital Audio 和已登记 CC0 音效。未列入来源表的包不得直接复制到 `app/src/main/assets/`。

## 4. 目录、命名与元数据

- 运行时图片：`app/src/main/assets/gfx/levels/level_XX/`；文件使用 `snake_case`，例如 `magnetic_crate.png`、`boss_r30_weakpoint_02.png`。
- 运行时音频：`app/src/main/assets/audio/levels/level_XX/`；按 `ambience_*.ogg`、`sfx_*.ogg`、`boss_phase_*.ogg` 分类。
- 关卡配置：`app/src/main/assets/levels/level_XX.json`，只引用本地资源 ID，不写绝对路径或网络 URL。
- 离线生成源：`art/generated/levels/level_XX/`；保存脚本、参数和许可证副本，不直接作为 Android 资源目录。
- 元数据：每关配 `asset_manifest.json`，字段至少包含 `asset_id`、`kind`、`path`、`width/height` 或 `sample_rate/duration`、`source`、`license`、`sha256`、`generator`、`fallback`。
- 证据：`.scratch/50-level-expansion/audits/assets/level-XX/` 保存清单、导出日志、接入截图和低性能对比。

## 5. 导入和优化流水线

1. **登记：** 先在 `ASSET_SOURCES.md` 写来源和许可证，再把压缩包放入 `tmp/third_party/<slug>/`；不得直接从浏览器缓存或任意个人目录复制。
2. **审查：** 运行尺寸、颜色、透明度、文件名、许可证和商业表达检查；未知元数据先隔离到 `tmp/` 候选区。
3. **原创化：** 对 CC0 图块做统一调色/裁切/重组；对参考模型只渲染为项目原创 2D 轮廓；不得导入带原作者商标或演示关卡布局的整体图。
4. **归一化：** 图片转为目标尺寸 PNG/WebP（保留透明通道）；音频转 OGG 48 kHz 或项目统一采样率，峰值留 1 dB headroom；删除未使用帧和元数据。
5. **接入：** 在 `AssetRepository` 注册 ID，配置缺失时回退到程序化占位；关卡 JSON 只能引用注册 ID。资源加载失败不得阻断主菜单。
6. **验证：** 运行静态资源检查、离线启动、低性能模式、APK 解包清单检查和 SHA-256；验证无 HTTP 请求、无外链字体、无越界纹理。

## 6. 低性能与无资源回退

- 图片缺失：用相同 token 的 Canvas 几何、轮廓和渐变绘制替代，不显示空白矩形。
- 音频缺失：使用本地合成的短提示音；关键危险预警同时显示闪烁轮廓/箭头，确保静音设备仍可玩。
- 复杂粒子：按 `PerformanceMode` 降级为单层渐变和固定轮廓，不改变碰撞、伤害、检查点或 Boss 阶段逻辑。
- 章节 Boss 资源缺失：使用程序化分层轮廓和阶段色，仍需显示弱点、预警和阶段 HUD；验收记录回退是否触发。

## 7. 交付门槛与禁止项

每个关卡工单关闭前必须具备：资源清单、来源/许可证记录、SHA-256、离线构建日志、低性能截图、真实设备或模拟器录屏索引。禁止提交密钥、签名文件、个人路径配置、构建缓存、下载临时文件和未审查的第三方素材。禁止为了赶进度把占位素材标记为最终资源；占位必须在工单中明确且有替换计划。

素材包只在开发机离线构建时生成和导入；APK 发送给测试者后即使断网也必须完整运行。任何新增来源或许可变更都要与对应关卡工单同一提交，确保文档、代码、资源清单和验收证据一致。
