**Blocked by:** None (can start immediately)

**Status:** complete

- [x] Acceptance matrices cover CG, voice, character interaction, combat, level pacing, UI/save, offline behavior, performance, and installation.
- [x] Every later ticket has a verifiable demo path and a single owner of its acceptance evidence.
